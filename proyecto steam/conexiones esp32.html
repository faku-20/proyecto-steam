1. Resumen del proyecto


El proyecto consiste en una maqueta funcional de un sistema de riego remoto para simular la curación por humectación de ladrillos ecológicos.


La maqueta usa un ESP32 como controlador principal. El ESP32 crea una red WiFi local llamada CuradoLadrillos, genera una página web propia y permite activar una mini bomba de agua mediante botones desde un celular o computadora.


El sistema demuestra la cadena principal:



Celular o computadora -> WiFi del ESP32 -> página web local -> relé -> mini bomba -> riego -> drenaje

La versión UTU trabaja en baja tensión y está pensada como prototipo seguro, demostrable y educativo.


2. Problema que busca resolver


Los ladrillos ecológicos no se curan mediante quemado en horno, sino manteniendo humedad durante el proceso de curado. Esto evita el uso de combustión, reduce impacto ambiental y permite un proceso más eficiente.


El problema práctico es que mantener la humedad puede requerir presencia humana, control manual de la bomba y supervisión constante.


El proyecto busca demostrar cómo automatizar parcialmente ese proceso, permitiendo activar riego desde una interfaz simple.

Construir una maqueta funcional que permita:


  • Crear una red WiFi desde el ESP32.
  • Acceder a una página web local desde un celular.

  • Apagar la bomba automáticamente al terminar el tiempo.
  • Cortar el riego manualmente con un botón de emergencia en la página.
  • Mover agua real hacia una muestra o maqueta de ladrillos.
  • Recolectar el agua con una bandeja o drenaje simple.

10. Función del relé


El relé funciona como un interruptor controlado electrónicamente.


El ESP32 no debe alimentar directamente la bomba desde un pin GPIO, porque sus pines entregan poca corriente. En cambio:



ESP32 -> activa relé
Relé -> conecta o corta alimentación de la bomba

El relé separa el circuito de control del circuito de potencia de la bomba.


Importante: en la maqueta el relé solo controla baja tensión, por ejemplo 5V o 12V. No se debe usar 220V en esta etapa.


11. Plan de conexión conceptual


Ejemplo conceptual, usando un pin digital del ESP32:



ESP32 GPIO 26 -> IN del módulo relé
ESP32 GND     -> GND del módulo relé
ESP32 5V/VIN  -> VCC del módulo relé, si el módulo requiere 5V

Circuito de bomba:



Fuente + de bomba -> COM del relé
NO del relé       -> + de la bomba
- de la bomba     -> - de la fuente

Notas importantes:


  • Usar NO significa “normalmente abierto”, por lo que la bomba queda apagada al iniciar.
  • El negativo de la fuente de bomba y el GND del ESP32 pueden necesitar masa común, según el módulo relé usado.
  • Si el módulo relé tiene optoacoplador y alimentación separada, revisar el esquema específico del fabricante.
  • No conectar la bomba directamente a un pin del ESP32.

#include <WiFi.h>
#include <WebServer.h>

const char* ssid = "CuradoLadrillos";
const char* password = "12345678";

WebServer server(80);

const int RELAY_PIN = 26;

// Cambiar a false si el modulo rele se activa con HIGH.
const bool RELAY_ACTIVE_LOW = true;

bool pumpOn = false;
unsigned long pumpStartTime = 0;
unsigned long pumpDuration = 0;

void setPump(bool on) {
  pumpOn = on;

  if (RELAY_ACTIVE_LOW) {
    digitalWrite(RELAY_PIN, on ? LOW : HIGH);
  } else {
    digitalWrite(RELAY_PIN, on ? HIGH : LOW);
  }

  Serial.println(on ? "Bomba ENCENDIDA" : "Bomba APAGADA");
}

void startIrrigation(unsigned long durationMs) {
  pumpStartTime = millis();
  pumpDuration = durationMs;
  setPump(true);

  Serial.print("Riego iniciado por ");
  Serial.print(durationMs / 1000);
  Serial.println(" segundos");
}

void stopIrrigation() {
  pumpDuration = 0;
  setPump(false);
  Serial.println("Riego detenido manualmente o por tiempo cumplido");
}

void setup() {
  Serial.begin(115200);
  delay(500);

  pinMode(RELAY_PIN, OUTPUT);
  setPump(false);

  Serial.println("Iniciando sistema de riego...");
  Serial.println("Creando red WiFi local...");

  WiFi.softAP(ssid, password);

  IPAddress ip = WiFi.softAPIP();

  Serial.print("Red WiFi: ");
  Serial.println(ssid);
  Serial.print("Contrasena: ");
  Serial.println(password);
  Serial.print("Abrir en navegador: http://");
  Serial.println(ip);

  server.on("/", handleRoot);
  server.on("/regar5", handleWater5);
  server.on("/regar10", handleWater10);
  server.on("/regar20", handleWater20);
  server.on("/apagar", handleStop);

  server.begin();

  Serial.println("Servidor web iniciado");
  Serial.println("Sistema listo. Bomba apagada por seguridad.");
}
